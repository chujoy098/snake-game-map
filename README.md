# How2Play
1) Скачать репозиторий
2) Компилировать в терминале -  g++ main.cpp main.h.
3) !!ФАЙЛ map.txt ДОЛЖЕН БЫТЬ В ТОЙ-ЖЕ ПАПКЕ ЧТО И ПОЛУЧИВШИЙСЯ EXECUTABLE
4) Запустить игру через sudo ./a.out
# Mapmaking guide/Как создавать карты

X - Стена O - Еда  Пробел - Пустое место
Нужно создать или изменить предоставленный файл map.txt.
Карту лучше огородить стенкой справа, чтобы пробелы точно сохранились.
